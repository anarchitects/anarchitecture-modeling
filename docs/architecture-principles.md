## Scope and evidence

Reviewed local default branch at `721620c172e3fbb2fd1edc0699e483a310c296f6`: both existing ADRs, [public API inventory](consumer/api.md), and [session history proof](proofs/session-history.md). That published baseline exposes bounded command/defaulting/history mechanisms, not a general semantic snapshot comparator. ADR 0003 was subsequently accepted through PR #74; the [unreleased implementation record](proofs/semantic-comparison.md) distinguishes local evidence from publication and consumer adoption.

XML export, Git-backed storage/version control, durable audit, product impact analysis, domain conversion, deployment and editor presentation remain outside this proposal. A consumer decides how an explained semantic change affects its own business workflow.

The [ADR index](adr/README.md) is the decision entry point. This register owns only the two generic principles above and does not reproduce private consumer or ecosystem documents.
